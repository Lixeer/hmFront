# WebSocket 连接问题诊断指南

## 需要收集的信息

### 1. 浏览器控制台日志

请按以下步骤操作：
1. 打开浏览器访问页面
2. 按 F12 打开开发者工具
3. 切换到 Console 标签
4. 刷新页面
5. 等待连接断开
6. 复制所有日志内容

### 2. 网络请求日志

请按以下步骤操作：
1. 按 F12 打开开发者工具
2. 切换到 Network 标签
3. 在筛选框中输入 "WS"
4. 刷新页面
5. 点击 WebSocket 连接查看详情
6. 切换到 Frames 标签
7. 截图或复制日志

### 3. 后端服务器日志

请查看后端控制台输出，特别是包含以下关键字的日志：
- `WebSocket`
- `ping`
- `pong`
- `连接`
- `关闭`

## 常见错误代码说明

| 代码 | 含义 | 可能原因 |
|------|------|---------|
| 1000 | 正常关闭 | 主动断开连接 |
| 1001 | 端点离开 | 浏览器/页面关闭 |
| 1002 | 协议错误 | 消息格式错误 |
| 1003 | 不支持的数据类型 | 发送了不支持的数据 |
| **1006** | **异常关闭** | **网络问题/超时/服务器断开** |
| 1007 | 数据格式错误 | JSON 解析失败 |
| 1008 | 策略冲突 | 违反服务器策略 |
| 1009 | 消息过大 | 发送的消息超过限制 |
| 1010 | 需要扩展 | 客户端需要特定扩展 |
| 1011 | 服务器错误 | 服务器内部错误 |

## 快速检查清单

### 前端检查
- [ ] WebSocket URL 是否正确
- [ ] 端口是否被占用
- [ ] 网络是否正常
- [ ] 是否有防火墙阻止

### 后端检查
- [ ] 服务是否正常运行
- [ ] WebSocket 端点是否正确配置
- [ ] 是否有连接数限制
- [ ] 是否有超时配置

### 网络检查
- [ ] 是否有代理服务器
- [ ] 是否有防火墙规则
- [ ] 是否有 SSL/TLS 配置问题

## 测试命令

### 检查端口占用

```bash
# Windows
netstat -ano | findstr :8080
netstat -ano | findstr :3000

# 停止占用进程
taskkill /F /PID <进程ID>
```

### 测试 WebSocket 连接

```bash
# 使用 wscat（需要先安装：npm install -g wscat）
wscat -c ws://localhost:8080/ws/monitor
```

## 如果问题仍然存在

请提供以下信息：

1. **浏览器类型和版本**：
   - 例如：Chrome 120.0.0.0

2. **操作系统**：
   - 例如：Windows 10

3. **完整的错误日志**：
   - 浏览器控制台日志
   - 后端服务器日志

4. **网络环境**：
   - 是否在公司内网/VPN
   - 是否有代理服务器

5. **问题复现步骤**：
   - 如何操作才能触发问题
   - 是否每次都发生
